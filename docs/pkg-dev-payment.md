# pkg-dev 收款方案（怎么收钱、在哪收、收完怎么交付）

> 配套 `pkg-dev-pricing.md`（定价：免费/个人 ¥99/团队 ¥299/企业定制）。
> 本文回答三个问题：**在哪收钱、怎么收、收完后怎么交付密钥**。
> 分三阶段演进：个人起步（零门槛）→ 个体户/公司（正规化）→ 平台化（自动化）。

---

## 一、收款渠道（分阶段）

### 阶段 1：个人起步（0 成本，今天就能用）

| 渠道 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **微信收款码 / 支付宝收款码** | 秒到账、零门槛 | 个人码收款有限额（微信个人码 20 万/年） | 试用者付款 |
| **微信赞赏码 / 支付宝打赏** | 完全免费开通 | 无订单管理 | 首批种子用户 |
| **闲鱼/淘宝店（虚拟商品）** | 平台担保交易、有订单记录 | 需实名开店、抽佣 | 有淘宝/闲鱼账号 |
| **知识星球/小报童** | 会员制、内容承载 | 平台抽佣 | 打包"包+教程" |

**推荐起步组合**：微信收款码（主力）+ 闲鱼链接（有订单记录）。

### 阶段 2：个体户/公司（月入过万后升级）

| 渠道 | 说明 |
|---|---|
| **微信支付商户号**（个人可申请"小微商户"） | 官方收款、有订单 API、可对接自动发密钥 |
| **支付宝当面付/电脑网站支付** | 同上 |
| **Stripe / PayPal**（海外开发者） | 国际信用卡、自动订阅 |

### 阶段 3：平台化（规模化后）

- 自建收款页（微信支付 API 对接）
- 或上架 **DeepSeek 插件市场 / 类似 AI 应用市场**（如果有）

## 二、交付流程（收完钱怎么给密钥）

### 手动交付（阶段 1，起步够用）

```
1. 用户付款（微信/支付宝/闲鱼）→ 截图或订单号发你
2. 你用 key-issue.mjs 生成正式密钥（PRO-/TEAM-/ENT- 前缀）
3. 微信/邮件发给用户
4. 用户 yihe_license op=activate pack_id=<包id> key=<密钥> 激活
```

**关键**：密钥生成要用 `key-issue.mjs`（见第四节），**不要再用 PRO-WORKYIHE-28 这类公开演示密钥**。

### 自动交付（阶段 2，对接支付 API 后）

```
用户付款 → 支付回调 → 服务端生成密钥 → 自动返回/邮件发送 → 激活
```

## 三、密钥签发工具 key-issue.mjs（配套交付）

用脚本签发正式密钥 + 台账记录（买主/档位/时间/包），替代手写密钥。

```bash
node key-issue.mjs --tier pro --pack pkg-dev --buyer 张三 --out keys.json
# 输出: PRO-XXXX-XXXX-XXXX-XXXX  + 台账追加
```

台账（keys.json）：
```json
{
  "keys": [
    { "key": "PRO-9F3A-2B7C-4D1E-8A5F", "tier": "pro", "pack": "pkg-dev", "buyer": "张三",
      "issued_at": 1787971200000, "status": "active", "activated_at": null }
  ]
}
```

**密钥格式**：`<PREFIX>-<16位随机大写字母数字>`，前缀 PRO-/TEAM-/ENT- 决定档位（与 activateLicense 校验一致）。

## 四、收款对账（每单可查、每月可结算）

| 动作 | 工具 |
|---|---|
| 查看用量与费用 | `yihe_license op=usage`（消费方/配额/超额/费用） |
| 导出账单 | `yihe_license op=export`（结构化 JSON 对账） |
| 密钥台账 | `key-issue.mjs` 的 keys.json |
| 全局回传 | `telemetry-merge.mjs`（跨实例使用汇总） |

**月结流程**：月底 `export` 账单 + keys.json 台账 → 核对付款记录 → 生成结算单。

## 五、合规要点（重要）

| 事项 | 建议 |
|---|---|
| **个人收款合规** | 阶段 1 个人码收款属"经营所得"，月入过万应升级个体户/公司并开票 |
| **发票** | 个人开发者可代开（税务局代开发票，低税率）；有公司后自行开票 |
| **退款政策** | 写明"密钥一经激活不退"（数字商品），售前说明清楚 |
| **隐私** | 买主信息（姓名/联系方式）按最小化收集，仅用于交付与售后 |
| **税务** | 记得申报（微信/支付宝流水可导出） |

## 七、风险与边界

- **密钥防破解**：当前 activateLicense 是本地校验（演示级）；规模化后密钥应服务端签发 + 在线校验
- **盗版**：zip 分发可被复制，但**激活仍需密钥**（无密钥包可安装但 reason 受限/无商业功能）
- **信任**：种子用户反馈是最大增长引擎——**先服务好前 10 个付费用户**
